問題画面の下半分に重なります。上半分を見ながら調整できます。

遊び方

4つの数字は並び順が決まっています。間に演算子を置いて、答えを 10 にしてください。

操作

  • 下の記号をつまんで式の中へ。置ける場所に隙間が開きます
  • 置いた記号を式の外へ出すと外れます
  • 演算子は、置いてある演算子の上に重ねると差し替わります
  • 括弧は ( と ) を別々に置きます。相手がいない括弧は赤くなります

計算のきまり

  • ^ は右から計算します。2 ^ 3 ^ 2 は 2 ^ ( 3 ^ 2 )
  • 0 ^ 0 は 1 です
  • 階乗は 12! まで。3!! とは書けません。( 3! )! と書きます
  • 0 で割る式は正解になりません

モード

  • 本編 … 1000問。だんだん難しくなります
  • フリープレイ … ランダムに出題。何問でも遊べます
  • 挑戦モード … 100問クリアで解放。かなりの難問です

ヒント

3段階です。押すたびに少しずつ答えに近づきます。
